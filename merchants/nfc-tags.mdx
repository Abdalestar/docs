NFC tags let customers stamp their card or earn points by tapping their phone against a physical tag, instead of scanning a QR code. Each tag arrives already programmed, you set what it does when tapped from the dashboard, and you place it somewhere in your location.

</Frame>

## How NFC tags work

When a member taps their phone on an NFC tag, Qtap reads the address written on the tag and performs the action you've configured — adding a stamp to a specific stamp card, awarding points, or recording a check-in. The tap is logged with a timestamp and linked to the member's account.

Each tag belongs to your organization and can optionally be assigned to a specific location.

<Note>
NFC tags are physical items you order through the dashboard. Go to **Settings → Billing** and look for the NFC Tags add-on ($19 per tag).
</Note>

## Getting a tag onto your account

Every tag carries one permanent web address, written to the hardware before it reaches you. That address is what a tap reads, and it cannot be created from the dashboard, so tags are added to your account by Qtap rather than by you.

<Warning>
The **Add Tag** button on the NFC Tags page opens a form, but saving it does not work. Whatever you type, the dialog answers **Failed to add NFC tag** and nothing is added to your list. Order your tags under **Settings → Billing**, then ask Qtap support to put them on your account.
</Warning>

### What the serial number is for

The serial number is a note to yourself. It plays no part in making a tap work, so some of your tags will have one and some will not, and a tag with that field empty records taps normally. Taps are matched on the address written to the tag, which never changes and which you never have to type.

## Setting up what a tap does

Once a tag is on your list, its behaviour is yours to set and change as often as you like. Open the tag's three-dot menu, choose **View Details**, then click **Edit**:

- **Name**: how you recognise it, such as `Counter Tag` or `Table 5`. Customers never see it.
- **Location**: the branch the tag sits in, so its taps count toward that branch.
- **Action**: **Add Stamp**, **Award Points**, or **Check-In**.
- **Points Value**: what a tap is worth on a points tag.
- **Active**: switch a tag off without deleting it.

Click **Save Changes** when you are done.

<Frame caption="The Edit panel on a tag's detail page: rename the tag (1) and move it to another branch (2). Points Value appears here only when the action is Award Points.">
  <img src="/images/merchants/nfc-tags/nfc-tag-edit-panel.png" alt="Edit NFC Tag panel with the Name field and the Location dropdown called out, above the Action select, Active switch, and Save Changes button" />
</Frame>

<Warning>
The Edit panel has no field for the stamp card or the points program a tag credits, and nowhere else in the dashboard sets one either. If a tap answers that the tag is not linked to a card or a program, ask Qtap support to link it.
</Warning>

## Managing your tags

The NFC Tags page shows all registered tags in a table. You can filter by name or serial number using the search field, or narrow by status using the **Status** dropdown (Active / Inactive / All).

Each row shows:
- **Name** and serial number
- **Action** configured for that tag
- **Location** assignment (or "Unassigned" if none)
- **Taps** — total number of times the tag has been tapped
- **Last Tapped** — the date of the most recent tap
- **Status** — Active or Inactive

<Frame caption="Open any tag's three-dot menu to view its details, assign a location, deactivate it, or delete it.">
  <img src="/images/merchants/nfc-tags/03-tag-menu.png" alt="Tag row menu showing View Details, Assign Location, Deactivate, and Delete" />
</Frame>

### Changing a tag's location

Click the three-dot menu on any tag row and select **Assign Location**. Pick a location from the dropdown and confirm. You can also change this on the tag's detail page.

### Deactivating a tag

Click the three-dot menu and select **Deactivate**. Inactive tags remain in your inventory but won't process taps. Use this if a tag is damaged or misplaced temporarily.

### Viewing tap activity

Click **View Details** on any tag to open its detail page. You'll see:

- Total tap count, action type, location assignment, and current status
- A line chart showing taps over the last 7 days
- A list of recent taps with timestamps

<Frame caption="A tag's detail page shows its total taps, action, location, and status, plus its serial number and key dates.">
  <img src="/images/merchants/nfc-tags/04-tag-detail.png" alt="NFC tag detail page with stat cards and a details panel" />
</Frame>

### Deleting a tag

Click **Delete** from the three-dot menu. This removes the tag from your dashboard permanently. All tap history for that tag is also deleted and cannot be recovered.

<Warning>
Deleting a tag cannot be undone. If you want to stop using a tag temporarily, deactivate it instead.
</Warning>

## Stats at a glance

At the top of the NFC Tags page, four summary cards show:
- **Total Tags** — how many tags are on your account
- **Active Tags** — how many are currently active
- **Total Taps** — combined tap count across all tags
- **Unassigned** — tags not linked to any location
